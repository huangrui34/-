一键部署上线

前置条件（必须先完成！）
1. 电视开启ADB调试
路径：设置 → 账号与安全 → ADB调试 → 开启
部分型号：设置 → 关于 → 连续点击「版本号」7次 → 返回设置 → 开发者选项 → ADB调试

2. 确保电脑和电视在同一网络
电脑能ping通电视IP即可

3. 首次连接需在电视上点击「允许」
点击部署后，电视上会弹出「是否允许USB调试」对话框，请勾选「始终允许」并点击「允许」
